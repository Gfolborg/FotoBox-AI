# AI Prompt Change Checklist

Use this checklist before changing any prompt or image-generation flow.

- Square size required (2048x2048) when needed?
- Edge-to-edge composition required (no padding/borders/bars)?
- "Fill the entire frame" included?
- "Photorealistic" included?
- "No text/watermarks" included?
- Placement is natural with realistic lighting/shadows?
- Prompt changes applied in both client and server (if applicable)?
